# Gestão de Temporada

SaaS de gestão imobiliária para locação de curta temporada (Airbnb) e de longa duração, com contabilidade e relatórios fiscais brasileiros.

**Este é o repositório de produção.** O deploy roda na Railway (projeto `zonal-elegance`, serviço `gestao_temporada`) em https://www.gestor.gpscontabil.com.br, automaticamente a cada push na branch `main`.

Detalhes de stack, comandos, arquitetura e regras do domínio estão em [CLAUDE.md](CLAUDE.md). Histórico funcional em [todo.md](todo.md).

> Existe um repositório antigo e desatualizado chamado `gestao_temporada` na mesma conta — ele não é mais usado; este aqui é a fonte da verdade.
